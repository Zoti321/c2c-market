## 目标

在 MVP 买家闭环上增加：**首页入口的商品搜索**（FakeStore 全库客户端过滤）与 **最近浏览**（Room 持久化、我的 Tab 展示）。

## 1. 搜索

### 1.1 入口与导航

| 项 | 决定 |
|----|------|
| 入口 | 首页 `TopAppBar` **actions** 搜索图标（`Icons.Outlined.Search`） |
| 目标 | push 全屏 `SearchScreen`（隐藏 Bottom Nav，同商品详情） |
| 路由 | `search`（`Routes.SEARCH`） |
| 返回 | TopAppBar 返回 / 系统 Back → `popBackStack` |
| 分类 Tab | v2.1 **不做**分类内搜索 |

### 1.2 搜索行为

FakeStore **无搜索 API**，全库 **20 条** → **一次拉全量 + 客户端过滤**。

| 项 | 决定 |
|----|------|
| 数据源 | `GET /products`（无 limit，一次 20 条） |
| 匹配字段 | `title` **contains**（不搜 description，减少误匹配） |
| 大小写 | 忽略（`lowercase()` 比较） |
| 防抖 | 300ms（`Flow.debounce`） |
| 空 query | 不请求；展示占位文案「输入商品名称搜索」 |
| 无结果 | Empty 态：「未找到相关商品」 |
| 结果 UI | 与首页相同 `ProductCard`，**LazyColumn 单列**（搜索页不用网格，便于扫标题） |
| 点击结果 | `navigate(Routes.product(id))` |
| 网络失败 | 共用 `ErrorContent` + 重试 |

### 1.3 数据层

```
SearchScreen → SearchViewModel → ProductRepository.searchProducts(query)
```

**Repository 扩展**（`ProductRepository`）：

```kotlin
suspend fun getAllProducts(): Result<List<Product>>
fun searchProducts(query: String): Flow<SearchResult>
```

- `getAllProducts()`：调用 `FakeStoreApi.getProducts()`，映射 `ProductDto → Product`
- `searchProducts(query)`：
  - `query.isBlank()` → `SearchResult.Idle`
  - 否则 emit `Loading` → 调 `getAllProducts()` → 内存 filter → `Success(list)` 或 `Error`
- **内存缓存**：`FakeStoreProductRepository` 内 `allProductsCache: List<Product>?`，首次成功后缓存；App 进程内有效（不持久化 Room）
- UI **不直连** Retrofit / DAO

```kotlin
sealed interface SearchResult {
    data object Idle : SearchResult
    data object Loading : SearchResult
    data class Success(val products: List<Product>) : SearchResult
    data class Error(val throwable: Throwable) : SearchResult
}
```

## 2. 浏览历史

### 2.1 记录时机

| 项 | 决定 |
|----|------|
| 触发 | `ProductDetailViewModel` 在 `getProduct` **成功**后调用 `BrowseHistoryRepository.recordView(product)` |
| 去重 | 同一 `productId` **upsert**：更新 `viewedAt`，不新增重复行 |
| 失败详情 | **不记录**（NotFound / Network 不写历史） |
| 来源 | 首页 / 分类 / 搜索 / 历史本身再进详情，均记录 |

### 2.2 Room 模型

**Entity** `BrowseHistoryEntity`（表 `browse_history`）：

| 列 | 类型 | 说明 |
|----|------|------|
| `productId` | INT, PK | FakeStore 商品 id |
| `title` | TEXT | 快照 |
| `imageUrl` | TEXT | 快照 |
| `price` | REAL | 快照 |
| `viewedAt` | INTEGER | epoch millis，排序用 |

- **上限** 50 条：insert/upsert 后若超出，删除 `viewedAt` 最旧行
- DB 版本 **v2 → v3**（`MIGRATION_2_3`）
- 商品远程数据仍 **不缓存 Room**（仅浏览历史元数据快照）

**DAO** `BrowseHistoryDao`：

```kotlin
@Upsert suspend fun upsert(item: BrowseHistoryEntity)
@Query("SELECT * FROM browse_history ORDER BY viewedAt DESC LIMIT 50")
fun observeRecent(): Flow<List<BrowseHistoryEntity>>
@Query("DELETE FROM browse_history WHERE productId NOT IN (SELECT productId FROM browse_history ORDER BY viewedAt DESC LIMIT 50)")
suspend fun trimToMax(max: Int = 50)
@Query("DELETE FROM browse_history") suspend fun clearAll()
```

**Repository** `BrowseHistoryRepository`：

```kotlin
fun observeRecent(): Flow<List<BrowseHistoryItem>>  // domain 模型
suspend fun recordView(product: Product): Result<Unit>
suspend fun clearAll(): Result<Unit>
```

### 2.3 展示（我的 Tab）

| 项 | 决定 |
|----|------|
| 位置 | `ProfileScreen`：游客 Banner **下方**、订单区块 **上方** |
| 标题 | 「最近浏览」+ 右侧 TextButton「清空」（调用 `clearAll`） |
| 布局 | 横向 `LazyRow`，卡片：缩略图 64dp + 标题单行省略 + 价格 |
| 空历史 | **不展示**该区块（无标题、无占位） |
| 点击 | → `product/{id}` |
| 订单区块 | 保持 MVP 行为不变 |

## 4. UI 状态矩阵（v2.1 增量）

| 屏幕 | Loading | Error | Empty | Success |
|------|---------|-------|-------|---------|
| Search | 首次查询前不 Loading；有 query 且拉取中 → 居中 Indicator | ErrorContent + retry | 有 query 无匹配 | ProductCard 列表 |
| Profile 最近浏览 | — | — | 隐藏区块 | LazyRow |

搜索页 **Idle**（无 query）不算 Loading/Empty，显示引导文案。

## 6. v2.1 明确不做

- 搜索 **关键词历史**（只记录浏览过的商品，不记录输入过的 query）
- 搜索 **建议 / 热门**
- 按 **description / category** 搜索
- **分类 Tab** 内搜索入口
- ~~**v2.2 挂牌** 纳入搜索结果~~ → **v2.2 已锁定**：搜索合并本地挂牌，见 [`v2.2-local-listings.md`](v2.2-local-listings.md) §3.3
- 下拉刷新搜索缓存
- 浏览历史 **单条删除**（仅「清空全部」）

## 7. v2.1 验收清单（供后续验收票）

### 搜索

- [ ] 首页 TopAppBar 搜索图标 → 进入搜索页
- [ ] 输入关键词（如 "bag"）→ 防抖后展示匹配商品
- [ ] 无匹配 → 空态文案
- [ ] 点击结果 → 商品详情
- [ ] 断网 → Error + 重试可恢复

### 浏览历史

- [ ] 进入商品详情并成功加载 → 我的 Tab「最近浏览」出现该商品
- [ ] 再次进入同一商品 → 历史顺序更新（最近在前）
- [ ] 点击历史项 → 详情页
- [ ] 「清空」→ 区块消失
- [ ] 重启 App → 历史仍在（Room）

### 架构（抽查）

- [ ] UI 不直连 Retrofit / DAO
- [ ] `ProductDetailViewModel` 通过 `BrowseHistoryRepository` 写历史
