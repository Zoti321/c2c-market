# MVP 功能边界与验收标准

> **关联 Issue**：[锁定 MVP 功能边界与验收标准](https://github.com/Zoti321/c2c-market/issues/5)  
> **锁定日期**：2026-09-18  
> **状态**：已锁定

## 目标

打通买家闭环：**浏览商品 → 加购/收藏 → Mock 结算 → 查看订单**；以**游客**身份使用，无登录与真支付。

---

## 1. 四个 Tab 最小行为

### 首页

- Paging 3 商品网格（或列表），数据来自 FakeStore
- 点击商品进入详情（push 全屏）
- Loading / Error / Empty（无商品时）

### 分类

- 展示 FakeStore 四分类列表
- 点击分类 → 该分类下的商品列表
- Loading / Error / Empty（该分类无商品时）

### 购物车

- Room 持久化行项：缩略图、标题、单价、数量
- 支持改数量、删除单行
- 底部合计 +「去结算」
- 空态文案 + 引导回首页
- **不做全选**；结算对象为购物车全部商品

### 我的

- 展示「游客」身份标识（固定本地游客 ID，无需登录 UI）
- **订单列表**入口（主内容）
- 点击进入订单详情
- 订单空态
- **不含**收藏列表 Tab 入口（收藏在详情页操作）
- **不含**深色模式手动开关

---

## 2. 商品详情页

### 展示字段

| 字段 | 必须 |
|------|------|
| 图片（Coil） | ✅ |
| 标题 | ✅ |
| 价格 | ✅ |
| 分类 | ✅ |
| 描述 | ✅ |
| 评分（rating） | 可选（有空间则展示） |

### 操作

- **加入购物车** — 写入 Room，即时反馈（Snackbar 或按钮态）
- **收藏 / 取消收藏** — 写入 Room，Toggle 状态
- **不做**「立即购买」（必须经购物车 → 结算）

### 导航

- 从首页 / 分类商品列表 push 进入
- 系统 Back / TopAppBar 返回

---

## 3. 购物车规则

| 规则 | 决定 |
|------|------|
| 数量修改 | ✅ 步进器或输入 |
| 删除单行 | ✅ |
| 全选 | ❌ MVP 不做 |
| 结算范围 | 购物车全部商品 |
| 库存 Mock | **无限库存**（无上限校验） |
| 持久化 | Room SSOT，进程重启保留 |

---

## 4. Mock 结算流程

```
购物车「去结算」
  → 结算确认页（商品摘要列表 + 合计金额）
  → 用户点击「确认下单」
  → Room 写入 Order（含商品快照、总价、时间戳、游客 ID）
  → 清空购物车
  → 跳转订单详情或订单列表
```

| 项 | 决定 |
|----|------|
| 地址填写 | ❌ MVP 不做（v2.3） |
| 真支付 | ❌ |
| 游客 ID | 固定本地 ID（ADR-0003） |
| 结算后购物车 | **清空** |

## 5. 订单

### 订单列表（我的 Tab）

- 展示历史 Mock 订单：订单号/时间、合计、状态
- 点击进入详情
- 空态：尚无订单

### 订单详情

- 商品快照列表、合计、下单时间、状态（如「已完成」）

## 7. 深色模式

- **仅跟随系统**（`isSystemInDarkTheme` / 现有 Theme）
- 不在「我的」提供手动开关（v2 可选）
- 验收时测试系统切换

---

## 8. MVP 明确不做

- 登录 / 注册 / Google Sign-In
- 真支付 SDK
- 搜索、浏览历史（v2.1）
- 卖家发布挂牌（v2.2）
- 私信 / 聊天（v3）
- Push、地图、Deep Link
- 下拉刷新
- 分享
- 收货地址 CRUD（v2.3）
- FakeStore `/carts` API（购物车走 Room）

## 9. MVP 验收清单

供 [#11 MVP 验收](https://github.com/Zoti321/c2c-market/issues/11) 使用。

### 功能

- [ ] 联网冷启动：首页 Loading → 商品 Paging 列表展示
- [ ] 首页点击商品 → 详情页：图片、标题、价格、分类、描述
- [ ] 详情页「加入购物车」→ 购物车 Tab 可见对应行项
- [ ] 详情页「收藏」→ 再次进入详情显示已收藏态
- [ ] 分类 Tab：展示四分类；点击 → 该分类商品列表
- [ ] 购物车：改数量、删除；空购物车显示空态
- [ ] 购物车「去结算」→ 确认页 → 确认 → 生成订单且购物车清空
- [ ] 我的 Tab：订单列表 → 订单详情，字段正确
- [ ] 游客身份有可见标识（如「游客模式」）

### 异常与体验

- [ ] 断网或请求失败：Error 文案 + 重试可恢复
- [ ] 无效商品 id（若可测）：Error 处理，不崩溃
- [ ] 屏幕旋转：ViewModel 保留列表/详情/购物车状态
- [ ] 系统切换深色模式：UI 正常、无硬编码浅色

### 架构（抽查）

- [ ] UI 不直连 Retrofit / DAO（代码审查或 Log 确认）
- [ ] 购物车、收藏、订单重启后仍在（Room 持久化）
