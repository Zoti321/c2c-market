# v2.5 测试范围与策略规格

> **关联 Issue**：[约定 v2.5 测试范围与策略规格](https://github.com/Zoti321/c2c-market/issues/25)  
> **锁定日期**：2026-09-19  
> **状态**：已锁定  
> **依据**：MVP 既有单测、v2.1–v2.4 规格

## 目标

为 v2 全部功能建立 **可重复、无 flaky 网络** 的测试基线：JVM 单测为主，Room 内存库集成测次之，少量 Compose 仪器冒烟；**不**做 FakeStore 真网 E2E。

---

## 1. 测试金字塔（本项目）

| 层级 | 运行命令 | 占比目标 | 说明 |
|------|----------|----------|------|
| **Unit**（JVM） | `./gradlew test` | ~80% | Repository、ViewModel、Worker 逻辑、纯函数 |
| **Integration**（JVM + Room in-memory） | `./gradlew test` | ~15% | DAO / Repository 事务 |
| **Instrumented**（设备/模拟器） | `./gradlew connectedDebugAndroidTest` | ~5% | 少量 Compose UI 冒烟 |

- **CI 门禁（v2.5）**：至少保证 `./gradlew test` 全绿（与 MVP 一致）
- **connected 测试**：本地 / PR 前手工跑；**不**强制 CI（v2.6 可选接入）

| 库 | 用途 |

## 3. 单元测试 — 必测清单

### 3.1 Data / Repository（JVM）

| 类 | 必测场景 |
|----|----------|
| `FakeStoreProductRepository` | 已有；补充 `getAllProducts` / `searchProducts` filter（v2.1） |
| `FakeStorePagingSource` | 已有 |
| `CartRepositoryImpl` | 加购、增量、删行、空购物车 |
| `FavoriteRepositoryImpl` | toggle 开/关 |
| `OrderRepositoryImpl` | `placeOrder` 写订单 + 清购物车；带 `ShippingInfo`（v2.3）；空购物车失败 |
| `BrowseHistoryRepositoryImpl` | record upsert、50 条 trim、observe 排序（v2.1） |
| `ListingRepositoryImpl` | create 负 catalogId、delete 清 cart/favorite、byCategory（v2.2） |
| `AddressRepositoryImpl` | 默认唯一、delete 默认晋升、校验失败（v2.3） |
| `WorkManagerOrderNotificationScheduler` | enqueue 被调用（Fake WorkManager 或 wrapper 接口 spy） |

远程 API 测试 **一律 MockWebServer**；禁止真连 `fakestoreapi.com`。

### 3.2 ViewModel（JVM + Fake Repository）

| 类 | 必测场景 |
|----|----------|
| `SearchViewModel` | 空 query Idle；有 query Success；filter 结果 |
| `CheckoutViewModel` | 无地址 `canPlaceOrder=false`；有地址下单 success event（v2.3） |
| `ProductDetailViewModel` | 负 id 走 listing；成功 record 浏览历史（v2.1） |
| `CreateListingViewModel` | 校验失败不提交；成功 emit navigate back |

- 使用 `kotlinx-coroutines-test` + `StandardTestDispatcher`；Flow 用 **Turbine**

### 3.3 Worker（JVM + work-testing）

| 类 | 必测场景 |
|----|----------|
| `OrderShippedNotificationWorker` | 有权限时 `doWork` success；无权限时 success 跳过（v2.4） |

- `NotificationHelper` 可抽接口便于 fake

### 3.4 UI 纯逻辑（JVM，已有）

| 类 | 说明 |
|----|------|
| `FlowUiState` / `asUiStateFlow` | 已有，保持 |

## 4. Room 集成测试（JVM）

使用 `Room.inMemoryDatabaseBuilder` + `runTest`：

| 测试类 | 场景 |
|--------|------|
| `OrderDaoTest` | `placeOrderWithClearCart` 事务：订单行 + 购物车清空 |
| `AddressDaoTest` | 设默认仅一条 |
| `ListingDaoTest` | catalogId 唯一 |
| `BrowseHistoryDaoTest` | upsert 更新 viewedAt |

- 放 `app/src/test/`，与 DAO 同包或 `data/local/` 子包

---

## 5. 仪器测试（androidTest）

### 5.1 策略

- **Hilt 测试入口**：`@HiltAndroidTest` + `HiltAndroidRule` + `@BindValue` Fake `ProductRepository`（固定 2 条假商品）
- **不依赖** FakeStore 网络
- 删除占位 `ExampleInstrumentedTest`（或替换）

### 5.2 必测 Compose 冒烟（≥3 条）

| 测试 | 断言 |
|------|------|
| `HomeScreenTest` | 假数据商品标题可见 |
| `CartScreenTest` | 空购物车显示空态文案 |
| `ProfileScreenTest` | 「游客模式」可见 |

- 使用 `createComposeRule()` + `onNodeWithText` / `testTag`（implement 时为关键节点加 `Modifier.testTag`，仅测试所需，≤5 处）

### 5.3 v2.5 仪器测试不做

- 全导航 E2E（首页 → 详情 → 加购 → 结算）
- 相册选图 / 通知权限弹窗
- 多设备尺寸截图

## 8. 执行与验收

### 8.1 本地命令

```bash
./gradlew test                    # 必过，v2.5 完成标准
./gradlew connectedDebugAndroidTest   # 推荐 PR 前手工
```

### 8.2 v2.5 完成标准

- [ ] §3 所列 **Repository** 单测全部存在且通过
- [ ] §4 **Room 集成** ≥3 个 DAO 测试通过
- [ ] §3.2 **ViewModel** ≥3 个测试通过
- [ ] §5.2 **Compose 冒烟** ≥3 条通过
- [ ] `./gradlew test` 全绿
- [ ] 无测试依赖真网

### 8.3 v2.5 明确不做

- JaCoCo 覆盖率百分比门禁（留 v2.6）
- GitHub Actions 跑 emulator（留 v2.6）
- Paparazzi / 截图回归
- Benchmark / Macrobenchmark
- Robolectric（统一 JVM + 少量 androidTest）
