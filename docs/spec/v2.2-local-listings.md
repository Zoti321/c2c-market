# v2.2 发布挂牌规格

> **关联 Issue**：[约定 v2.2 发布挂牌规格](https://github.com/Zoti321/c2c-market/issues/22)  
> **锁定日期**：2026-09-19  
> **状态**：已锁定  
> **依据**：[CONTEXT.md](../../CONTEXT.md)、[v2.1 搜索规格](v2.1-search-browsing-history.md)、[FakeStore 调研](../research/fakestore-api.md)、[ADR-0002 Room SSOT](../adr/0002-room-as-local-ssot.md)

## 目标

游客卖家可在 App 内 **发布本地挂牌**（相册选图、数据存 Room、不上传服务器），并与 FakeStore **商品** 在浏览、搜索、分类、详情、购物车链路中 **统一展示与交易**（仍 Mock 结算）。

---

## 1. 领域模型

### 1.1 商品来源

| 来源 | id 规则 | 数据 |
|------|---------|------|
| **Remote**（FakeStore） | 正整数 `1…20` | Retrofit |
| **LocalListing**（挂牌） | **负整数** `-1, -2, …` | Room |

- 统一使用现有 `Product` domain 模型，新增字段：

```kotlin
enum class ProductSource { REMOTE, LOCAL_LISTING }

data class Product(
    val id: Int,
    val title: String,
    val price: Double,
    val description: String,
    val category: Category,
    val imageUrl: String,       // Remote: https；挂牌: content://
    val rating: Rating,         // 挂牌固定 Rating(0.0, 0)，UI 不展示评分
    val source: ProductSource = ProductSource.REMOTE,
)
```

- **catalogId**：挂牌在 Room 中的对外商品 id = **负的 `listingId`**（`listingId` 为表自增 Long）；插入时分配 `catalogId = -(maxListingId + 1)` 或取当前最小 catalogId 再减 1
- 购物车 / 收藏 / 订单 / 浏览历史 **沿用 `productId: Int`**，无需改表结构；负 id 表示挂牌

### 1.2 Room Entity

**`ListingEntity`**（表 `listings`）：

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | INTEGER, PK, auto | 内部行 id |
| `catalogId` | INTEGER, UNIQUE | 负整数，对外 Product.id |
| `title` | TEXT | 必填 |
| `price` | REAL | 必填，> 0 |
| `description` | TEXT | 必填 |
| `category` | TEXT | FakeStore slug 四选一 |
| `imageUri` | TEXT | `content://` 字符串 |
| `createdAt` | INTEGER | epoch millis |
| `updatedAt` | INTEGER | epoch millis |

- DB 版本：**v2.1 的 v3 之上再 Migration → v4**（若 v2.1 未落地则 MVP v2→v3 合并 browse_history + listings，implement 时按实际版本链调整）
- 图片 **不上传**；仅持久化 URI

## 2. 发布与管理

### 2.1 入口

| 入口 | 行为 |
|------|------|
| 我的 Tab | 游客 Banner 下 **FilledTonalButton「发布挂牌」** → `CreateListingScreen` |
| 我的 Tab | **「我的挂牌」**区块（有数据时）：纵向列表，项可点进详情、侧滑或图标删除 |

### 2.2 发布表单（`CreateListingScreen`）

| 字段 | 控件 | 校验 |
|------|------|------|
| 图片 | `PickVisualMedia` 选 **1 张**；预览 1:1 缩略图 | 必选 |
| 标题 | `OutlinedTextField` | 非 blank，≤ 100 字 |
| 价格 | 数字输入 | `> 0` |
| 描述 | 多行 TextField | 非 blank，≤ 500 字 |
| 分类 | 下拉 / ExposedDropdownMenu | 四分类 slug（同 FakeStore） |

- 提交：**「发布」** → `ListingRepository.create(...)` → Snackbar 成功 → `popBackStack` 回我的
- 编辑：从「我的挂牌」项 **长按菜单「编辑」** 或详情页（自己的挂牌）TopAppBar 编辑图标 → 同表单预填，`update`
- 删除：我的挂牌列表删除图标 / 确认 Dialog → `delete`；**同步**从购物车、收藏移除该 `catalogId`（Repository 内事务）

### 2.3 图片 URI 持久化

```kotlin
// 选图后
context.contentResolver.takePersistableUriPermission(
    uri, Intent.FLAG_GRANT_READ_URI_PERMISSION
)
```

- Coil 加载 `content://` URI
- **不做**拷贝到 app 内部 storage（v2.2 保持简单；系统清权限时图片可能失效，可接受）

## 3. 聚合展示

### 3.1 首页

```
HomeScreen
├── [可选] 本地挂牌区块标题「附近挂牌」（有挂牌时）
├── LazyVerticalGrid 前 N 项：本地挂牌 ProductCard（同 Remote 样式 + 「挂牌」AssistChip）
└── 既有 FakeStore Paging 网格（不变）
```

- 挂牌 **排在 Remote 商品之前**
- 点击挂牌 → `product/{negativeId}`

### 3.2 分类 Tab

- `CategoryProductsScreen`：Remote 列表 **+** 同分类本地挂牌（合并为一个 LazyColumn，挂牌在前）
- 空态：Remote 与挂牌均为空时才 Empty

### 3.3 搜索（扩展 v2.1）

- `ProductRepository.searchProducts`：在 FakeStore 全量 filter 后，**追加**本地挂牌 title filter 结果（同样 ignoreCase contains）
- 挂牌与 Remote 混排：**挂牌在前**，再 Remote

### 3.4 商品详情

- 路由仍为 `product/{id}`
- `ProductDetailViewModel`：
  - `id > 0` → `productRepository.getProduct(id)`（FakeStore）
  - `id < 0` → `listingRepository.getProductByCatalogId(id)`
- UI 增量：
  - `source == LOCAL_LISTING` → 标题旁 **「本地挂牌」** AssistChip；**隐藏** rating 行
  - **加购 / 收藏** 行为与 Remote 相同
  - 自己的挂牌（游客仅一条卖家身份）：TopAppBar 显示 **编辑 / 删除**（可选实现：v2.2 仅在「我的挂牌」管理，详情页只读亦可 — **决定：详情页对挂牌显示编辑/删除**，与 Remote 区分）

### 3.5 购物车 / 结算 / 订单

- 无变更：行项快照 `imageUrl` 存 content URI 字符串
- Mock 结算、订单详情 **不区分** 来源

## 4. 架构分层

```
CreateListingScreen → CreateListingViewModel → ListingRepository → ListingDao
HomeScreen → HomeViewModel → ListingRepository.observeAsProducts() + ProductRepository.paging...
ProductDetailViewModel → ProductRepository | ListingRepository（按 id 符号）
SearchViewModel → ProductRepository.searchProducts（内含挂牌合并）
CategoryProductsViewModel → 合并 Remote + ListingRepository.byCategory
ProfileScreen → ListingRepository.observeMyListings()
```

**`ListingRepository`**（domain 接口）：

```kotlin
fun observeAsProducts(): Flow<List<Product>>
fun observeByCategory(category: String): Flow<List<Product>>
fun observeMyListings(): Flow<List<Product>>
suspend fun getProductByCatalogId(catalogId: Int): Result<Product>
suspend fun create(input: CreateListingInput): Result<Product>
suspend fun update(catalogId: Int, input: CreateListingInput): Result<Product>
suspend fun delete(catalogId: Int): Result<Unit>
```

- UI **不直连** DAO / ContentResolver（除 Composable 内 `PickVisualMedia` launcher，文件 URI 交给 ViewModel）

## 8. v2.2 明确不做

- 多图上传 / 图库
- 图片拷贝到 app 私有目录
- 挂牌审核、举报
- 真实卖家账号 / 登录
- 服务器同步
- 库存 / 售罄状态
- 地理位置
- 分类 Tab 新增「仅挂牌」假分类
- 首页 Remote 与挂牌 **交叉排序**（按时间混排）— v2.2 固定「挂牌块 + Remote Paging」

## 9. v2.2 验收清单（供后续验收票）

### 发布

- [ ] 我的 → 发布挂牌 → 选图、填表 → 发布成功
- [ ] 重启 App → 挂牌仍在
- [ ] 编辑 / 删除挂牌生效；删除后从首页消失

### 浏览

- [ ] 首页可见挂牌，带「挂牌」标识
- [ ] 分类页含同分类挂牌
- [ ] 搜索可搜到挂牌标题
- [ ] 挂牌详情：无评分、有「本地挂牌」标识
- [ ] 挂牌可加购、收藏、下单

### 架构（抽查）

- [ ] UI 不直连 DAO
- [ ] 负 id 挂牌与正 id FakeStore 商品不冲突
