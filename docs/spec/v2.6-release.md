## 2. R8 / 资源压缩

### 2.1 Gradle（`app/build.gradle.kts`）

```kotlin
buildTypes {
    release {
        isMinifyEnabled = true
        isShrinkResources = true
        proguardFiles(
            getDefaultProguardFile("proguard-android-optimize.txt"),
            "proguard-rules.pro",
        )
        signingConfig = signingConfigs.getByName("release")
    }
}
```

- 移除当前 `optimization { enable = false }` 占位

### 2.2 `app/proguard-rules.pro`（必含 keep）

| 区域 | 规则要点 |
|------|----------|
| **Retrofit / OkHttp** | 接口方法、`-keepattributes Signature, *Annotation*` |
| **kotlinx.serialization** | `@Serializable` DTO、`ProductDto` 等 |
| **Room** | Entity / DAO（Room 默认 consumer rules + 显式 keep Entity 字段） |
| **Hilt** | 依赖 AGP 默认 + `@HiltWorker` Worker 类 |
| **Navigation** | 保留 `Routes` 相关 args（若反射） |
| **Coil** | 默认足够；若有反射加载再加 keep |
| **Line numbers** | `-keepattributes SourceFile,LineNumberTable` 便于 crash 可读 |

### 2.3 验收

```bash
./gradlew assembleRelease
```

- **必须成功**；安装 release APK 后 smoke：冷启动 → 首页列表 → 进详情（真网 FakeStore）
- R8 后若出现 `ClassNotFoundException` / 反序列化失败 → 补 keep 规则

## 3. 签名

### 3.1 本地 Release 签名

| 文件 | 说明 |
|------|------|
| `keystore.properties.example` | 模板，**提交 Git** |
| `keystore.properties` | 真实配置，**已 gitignore** |
| `keystore/release.jks` | 本地 keystore 目录，**已 gitignore** |

**`keystore.properties.example`**：

```properties
storeFile=keystore/release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=release
keyPassword=YOUR_KEY_PASSWORD
```

**Gradle 逻辑**：

```kotlin
signingConfigs {
    create("release") {
        val propsFile = rootProject.file("keystore.properties")
        if (propsFile.exists()) {
            val props = Properties().apply { load(propsFile.inputStream()) }
            storeFile = rootProject.file(props.getProperty("storeFile"))
            storePassword = props.getProperty("storePassword")
            keyAlias = props.getProperty("keyAlias")
            keyPassword = props.getProperty("keyPassword")
        }
    }
}
```

- 无 `keystore.properties` 时：`assembleRelease` **失败并提示**复制 example（学习项目不静默回退 debug 签名）

### 3.2 CI 签名

- **CI 不配置** release 签名密钥
- CI **不跑** `assembleRelease`（避免无 secrets 失败）
- Release 包 **仅本地** 或维护者手动 CI workflow_dispatch 构建

## 4. GitHub Actions CI

### 4.1 文件

`.github/workflows/android-ci.yml`

### 4.2 触发

- `pull_request` → `main`
- `push` → `main`

### 4.3 Job

```yaml
runs-on: ubuntu-latest
steps:
  - uses: actions/checkout@v4
  - uses: actions/setup-java@v4
    with:
      distribution: temurin
      java-version: 17
  - run: chmod +x gradlew
  - run: ./gradlew test assembleDebug
```

- **门禁**：`test` + `assembleDebug` 全绿方可合并（与 CONTRIBUTING 一致）
- **不跑** emulator / `connectedDebugAndroidTest`

### 4.4 Branch Protection

- 文档提醒：在 GitHub Settings → Branches 为 `main` 启用 Required check `android-ci`（或 workflow job 名）

## 5. 产物与分发

| 产物 | 命令 | 用途 |
|------|------|------|
| Debug APK | `./gradlew assembleDebug` | 日常开发 |
| Release APK | `./gradlew assembleRelease` | 本地安装 / 分享 |
| Release AAB | `./gradlew bundleRelease` | **可选**；不强制 Play 上架 |

### v2.6 明确不做

- Google Play  Console 上架流程
- Firebase App Distribution
- CI 自动发版 / Tag release
- JaCoCo 覆盖率报告上传
- Baseline Profile / App Bundle 动态交付
